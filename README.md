# JCM - Juuzoz' Cheat Menu
A debug menu mod for Road to Vostok

The menu can be found in the inventory screen, by the map and crafting menu. It replaces the unused Nomads button.

# Current features

**Player**

* God Mode (No damage, no afflictions)
* Max Needs
* Noclip
* Infinite Stamina
* Infinite Weight Limit
* Infinite Ammo
* Infinite Weapon and Gear Durability
* Invisibility
* Never Jam
* Fast Running speed
* High Jump
* Keep Gear on Death
* Keep Gear on Quit
* Permadeath Disabled in Vostok
* Immortal Cat
---
**Item Spawner**

* Guns
* Magazines
* Ammo
* Medical
* Gear
* Attachments
* Food
* Keys
* Furniture
* And every other item in the game!
---
**World**

* Weather Control
* Time Skip
* Change Season (Summer/Winter)
* Forced Trader Restock
* Loot Container Reroll
* Teleporter
* Event Spawner
---

**Note:** Mod Configuration Menu is no longer a requirement, but it is supported. Things like run speed, jump height and keybinds can be adjusted there.

**Default hotkeys:**
* Noclip = Caps Lock
* Loot Container Reroll = Numpad 1
* Trader Restock = Numpad 2

(Again, all adjustable in MCM)

Everything is toggleable and cheats are disabled by default.
